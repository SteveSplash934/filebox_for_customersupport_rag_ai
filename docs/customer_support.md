# Returns and Exchanges Policy

## Return window
Unused items can be returned within **30 calendar days** of delivery when accompanied by proof of purchase.

## Exchange process
1. Ask the customer for the order number.
2. Confirm that the item is eligible for exchange.
3. Provide a return authorization number.
4. Explain that the replacement ships after the returned item is received and inspected.

## Exceptions
Personalized items and final-sale products are not eligible for standard returns.
